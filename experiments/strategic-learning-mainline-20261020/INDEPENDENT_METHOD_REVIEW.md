# 战略学习主线独立方法复核（2026-10-20）

结论：支持按已经登记的 T=2 做一次全策略 logits 软化初始化，然后使用新采集、严格认证的 TRAIN on-policy 对局进行一次 PPO 更新。它是有测量依据的探索干预，尚不是学习成功或等待行为收益。主要瓶颈不是“所有移动选择都被 prior64 饱和”，而是多数状态只有一个可选移动，再叠加 EndTurn 的低概率；温度只能处理后者及现有候选之间的采样分布。

本复核只读源码、既有 TRAIN/DEV 报告及原始认证 TRAIN 样本，另做 CPU 概率重放。没有原生游戏、GPU、优化器更新、新样本准入或 DEV 标签训练；搁置的运输/恢复 v4 未继续。

## 源码与真正的行为策略

`strategic-policy-v3/model.py` 的分数为

`actor(state,candidate) + prior_scale*tanh(heuristic_score/100)*move_bit + stop_bias*stop_bit`。

prior_scale 是 buffer，PPO 不会直接优化它；stop_bias 是可学习参数。encoder.py 的第13维确为上述启发式特征，EndTurn 的23维移动特征全部为零。actor 最后一层初始为零，因而初始动作偏好主要由固定先验和 stop_bias 提供。64 这个系数本身不能证明分布饱和，必须看编码后的分差、候选数和实际概率。

`onpolicy_broker_v2.py` 真实使用 CUDA `torch.multinomial(exp(log_softmax(logits)))`，不是 argmax。它归档被采样动作的 old_logprob/value；准入再做原采样器精确回放。根代理新审计使用5398检查点在旧 TRAIN 状态上的概率，是有效的状态诊断，但这些2588状态由7415行为检查点采集，并非5398的新 on-policy 轨迹。

为独立核验“实际 on-policy 是否没有探索”，本复核加载认证 TRAIN 八局及其真正行为模型74158291…，使用CPU逐行重算。检查点 SHA 与每行 policy_sha/episode provenance 一致；所选动作 logprob 与归档值最大绝对误差 `5.48314e-7`。这只是容差 CPU 核对，不冒称原 CUDA generator 精确回放。证据为 `independent-behavior-probability-01/AUDIT.json`。

| 真正行为模型7415，2588条TRAIN策略行 | 结果 |
|---|---:|
| 一移动候选 + EndTurn | 2017（77.94%） |
| 多移动候选 + EndTurn | 571（22.06%） |
| 实际采样 EndTurn | 21（0.81%） |
| 实际采样非 argmax | 466（18.01%） |
| 平均/中位 EndTurn 概率 | 0.5146% / 0.1841% |
| 按局等权平均 EndTurn 概率 | 0.5251% |
| 最大动作概率的中位数 | 0.99018 |
| 多移动行中，移动条件熵中位数 | 3.74419 nats |
| 合并相同下一步坐标后的条件熵中位数 | 1.30297 nats |

571个多移动行中，没有“多个候选却只有一个不同下一步”的行；但不同长期目标仍会共享部分下一步，候选索引熵不是独立物理动作的数量。实际非 argmax 有466次，直接反驳“采样从不探索”；低 EndTurn 概率和高整体 top-p 则确实显示大多数一移动行接近继续移动的确定选择。这是强概率偏置，不是所有概率数值下溢或全部梯度严格为零。

候选贫乏与概率偏置应分别记录。原生保留目标逻辑会在目标仍合法时收缩到一个移动，再追加 EndTurn；观察到一个移动本身仍不能证明该行一定由收缩造成，因为原池也可能本来只有一个目标。PPO 不能选择未发布的目的地。训练不能靠更多迭代弥补候选缺失，也不应为本次实验移除已经解决旧抖动的目标保留机制。

## T=2 的单因素含义与限制

根代理的5398 TRAIN状态重放与本复核结论一致：原均值 stop0.5217%、多移动条件熵中位3.746，说明移动候选分布并未普遍饱和。T2将 stop均值提高至5.0454%，median4.1504%，mean forward KL(parent||T2)=0.087625；符合事先给定的小到大温度门禁。T4的 stop均值已15.05%，超过上限。门禁是工程探索范围，不是最优性或战略收益保证。

`initialize_temperature.py` 同时将 actor 最后W/b、stop_bias、prior_scale 除2，critic不变，数学上是同一个一维变换 `logits -> logits/2`，而非四个独立调参。保存/加载后在2588 TRAIN观察上 logits/2 误差0、critic误差0、argmax全同；新检查点 d5908330…是显式 weights-only 初始化、优化器/RNG重置、梯度步0。这个设计可作为本轮唯一策略初始化因素。

需要精确命名：这是“温度等效的权重初始化”，不是在每次后续 forward 永久除以 T。训练后 finalW/stop_bias 可独立变化，参数梯度几何也不等同于外挂固定 softmax 温度。prior32仍固定。其初始确定策略没有改变；温度本身不能解释同一观察上的 argmax 改选，更不能被叫做已经学会等待或撤退。新轨迹因随机采样和后续世界变化会离开旧状态分布，5.05%不保证是新局的实际 stop频率。

本轮干预同时软化移动间分差和 move/stop 分差；因此即便效果变好，也不能只归因于“等待”。若将来需要隔离 stop偏置，应另预注册只改变 stop bias 的对照，而不是根据本轮结果临时增添搜索。缺乏同预算T1新训练对照时，也不能从新旧训练胜负差异单独识别温度的因果收益。

## PPO 与最小后续判断

`episode_balanced_ppo.py` 对每局选择行等权分配总 actor 质量，critic按每局步数加权，终局仅合法完成 win+1/loss-1。Move+EndTurn 数学上是自由选择，所以2017行不会被当成 forced 行剔除，这是正确的；它们主要提供停/走学习信号，只有571行能直接训练不同目的地选择。应把两类机会分开报告。熵项0.005与梯度裁剪0.5不能创造未给出的动作；稀有 stop 的信用分配仍弱。单局终局回报在居中优势里可被抵消的问题已由既有分析证实，本轮应保持八格同策略混合终局样本，不能退回单局反复训练或把不同采样父模型混起来。

建议保持本轮原生 runtime、候选规则、奖励、PPO权重与超参不变，按新T2父SHA重新采集八格 TRAIN，绝不复用旧7415行的 old_logprob 做T2 PPO。整批完成且真实执行、真实终局、精确采样准入后再更新；超时既不算负局，也不补造回报或部分更新。当前只推进一个学习器即可，无需扩展运输工程或并发规模。

采集后至少看：每局停/走采样次数、1-move与multi-move占比、两类熵/概率及KL、跨回合进展与实际终局/运行长度。稀有 stop 变多可能是有效等待，也可能只是浪费回合；终局收益仍需独立验证。PPO现有 conditional_KL 是采样动作近似量，不是每个状态的完整分类分布精确 KL；不要把它当作所有稀有动作都稳定的证明。

实际更新后报告CUDA优化器步数、actor/critic/stop_bias变化、可恢复检查点和同观察上的改选；这些与训练成绩、独立能力提升分开。评估优先比较T2初始化与训练后模型的CPU argmax；parent5398与T2在同观察上初始argmax同，仍可能因原生/NK顺序波动出现不同轨迹，不能把这种差异算温度收益。比较完整真实移动前缀与首个请求/策略差异，保留所有预定格，不筛局。

既有 DEV 5/8→6/8、21/2103改选是真实小型开发观察；其中有原生/NK历史先行分叉，且两臂从未策略EndTurn。它不能认证等待、撤退、人类战术学习或普遍强度。新的 DEV 即使换种子，历史见过的地图仍是开发集；不得把标签加入训练或称其为未触碰的最终测试。最终测试继续封存。

上述判断支持一个克制但真实的学习实验，不支持“prior导致全盘探索失效，降低它就会变强”。后续若收集/收益失败，应按候选覆盖、stop代价、终局信用分配和实际状态分叉定位，再决定下一项单因素变化。
