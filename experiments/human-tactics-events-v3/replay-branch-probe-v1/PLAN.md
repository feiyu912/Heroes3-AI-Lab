# 真实前缀重放与中途干预 probe v1

最多3场新游戏，只用已用训练图0/守方/seed2026101811。来源为planner-pilot-v1的horizon2完整轨迹，不碰dev/test。

第1局：全新进程、相同构造seed，逐步强制历史动作前缀，到step12仍执行原动作，之后用teacher2续跑。step0..12每步核验完整图SHA和完整合法动作列表，不能只比较胜负。结束后比较全部状态/动作/事件/终局。

第2局：重新启动全新进程，以相同方式核验到step12，在同一个可见图/合法动作集合下改成不同的合法WAIT，然后teacher2续跑至原生终局。证明可中途干预，而不仅能重放原有轨迹。保留完整前后观测、原生窗口和terminal事件。每局120秒上限、同全局池锁。

这不是snapshot/clone API：每个分支从开局重新执行前缀，成本随前缀长度增加。当前绑定没有clone/save/load；普通CGameState内存存档明确不序列化currentBattles。

同seed意味着原生隐藏RNG历史相同，但换动作会改变后续RNG消耗。不得依据这些分支的实际未来结果挑最优动作后，宣称它是公平部署MCTS/人类专家。此实验仅验证接口能力，0BC/0专家认证/0模型晋升，哪怕分支更好也只是该采样路径结果。

真正规划需仅从可见state生成独立未来随机rollouts，或验证不依赖actual seed的规则期望模拟并用独立实战评估；当前未具备此接口。
