# CPU preregistration — learned build exploration offset v1

Scope: CPU-only initialization intervention and evidence diagnosis. No native game, GPU sampler/learner, optimizer step, expert label or independent ability inference. Historical policy12 files, run-v1 tools, all native capsules, model checkpoints and existing samples stay frozen.

Primary parent: latest actual build-trained checkpoint SHA256 `34a6a86ea74d727338388db74e0ab3b9e16ec85e45ef46313757b1ac814538bc` (188 CUDA Adam steps). Reference only: schema5 initial `0dbbc4735e217e39a55dcd2f398b945bcb9ea6490525c86645843a5f1ac313f6`. Calibration uses only all3000 admitted TRAIN states in `/root/heroes3-ai-lab/evaluations/strategic-learned-build-training-01`, including all400 states with native legal build candidates. No DEV/final-test data is used to select bias.

Hypothesis: the shared movement prior and many build choices may leave low total build probability even though build is selectable. First verify the actual occurrence/probability of income-category native candidates. Zero sampled income actions alone does not establish absence or a specific cause.

One added trainable scalar `actor.build_bias` contributes exactly `build_bias * is_build` to each legal candidate logit. It belongs to the actor optimizer group; movement prior remains move-only, EndTurn bias remains stop-only, critic and feature columns remain unchanged. Existing actor MLP has a build-op input but no independent output offset for that op; changing that nonlinear pathway cannot generally guarantee a constant offset with other outputs/value unchanged. This explicit scalar is the smallest exact intervention and is not a label or reward modification.

Evaluate bias candidates **0.5,1,1.5,2,3,4** in that order. Choose the smallest for which mean total P(build) on the400 eligible TRAIN states reaches at least10%, provided it does not exceed20%. If the first crossing overshoots20% or none reaches10%, report no eligible candidate and stop; do not add or tune extra candidates against DEV. Report all candidates, forward/reverse KL, total variation, build probability quantiles/extremes and fraction above50%/90%. Report conditional nonbuild distribution and Move:EndTurn odds, which must stay unchanged within floating point tolerance. No broad strength claim.

Migration adds this scalar to the exact parent weights; independent new architecture/weights format and new training epoch `strategic-learned-build-exploration-v1`. Native action schema5 and actual capsule remain unchanged. Parent Adam/rollout/RNG are explicitly discarded for the architecture intervention; old on-policy samples are used only for calibration, never admitted as on-policy for the modified model. Any next update requires new native CUDA sampling from the new initialization, new source/epoch admission and independent paired evaluation. Do not hot-patch old model_io or source bindings.
