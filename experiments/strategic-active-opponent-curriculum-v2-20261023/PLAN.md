# TRAIN-only active-opponent difficulty calibration

The design uses only completed TRAIN evidence: two batches each lost all four NK cells; in the zero-prior batch all 29 actual recruit choices within the first three days had negative normalized advantage. Those purchases are not relabeled as good actions. Neither current nor earlier DEV choices or outcomes choose this design.

Only the two original TRAIN VMAPs are used. The original files remain unchanged. For each map and owned role (red player0 / blue player1), x1 is an exact ZIP copy; x2 and x4 change only every stack count of that actual owned starting hero. Pikeman20/archer10 become40/20 or80/40. Hero type/owner/skills/position, enemy armies, header, terrain, all resources, towns and town inventories are unchanged. The two original maps explicitly bind their unique hero objects to each player's header declaration; no role is guessed. MAP_MANIFEST.json registers each archive, ZIP entry content/compressed payload/metadata, and exact JSON paths. Only private worker maps are populated; shared runtime Maps are never written.

Fixed model is the zero-prior initialization151014, not an updated model. Native is the same qualified schema6 capsule02, CPU argmax against Nullkiller2, no sampling/admission/PPO or optimizer. Four base cells are two maps x two roles; seeds2026104300..4303 are shared across x1/x2/x4 for their corresponding base cell. Register exactly12 TRAIN-only calibration games: original x1 four, then x2 four, then x4 four. There is no extra grid, seed replacement or selective invalid-game deletion.

Only successful normal native terminals with source/runtime identity, full typed transactions and terminal/drain proof are scored. Any timeout, invalid game or unfinished transport aborts qualification and has no win/loss label. After all12 valid games, select the first boosted level in the predefined order x2 then x4 with at least2/4 actual NK wins. x1 is recorded as the original-strength reference. If neither boosted level reaches the threshold, select none and report unqualified; no additional boost or seed may be introduced. All12 cells are registered even if x2 reaches the threshold.

This threshold selects a possible next TRAIN difficulty. It is not an independent win-rate estimate, a claim of strength on unboosted maps, an expert course or PPO data admission. Winning trajectories are not automatically expert demonstrations. Final-test remains untouched. Native/RNG starting seeds are paired, but equal initial public observations do not establish identical hidden-world execution after policy paths diverge.

The source-preparation subtask performs only CPU map derivation, strict diff, source freezing and private prepare-only checks. It starts zero native/GPU processes and takes no resource lock. Root independently reviews this package before executing the bounded calibration. Runtime collection retains GPU-then-pool locks, ready-before-native startup and all frozen terminal/identity guards. Existing frozen policies/runs, native sources/binaries and historical evidence are not modified.
